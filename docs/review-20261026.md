# 公开数据与稳健性复核

本轮复现香港1991至2024年度WDI数据：预测目标为实际GDP年增长百分比，误差为百分点；16个样本外目标的回归RMSE 3.872006，历史均值3.947851，改善约1.9%。数据来源、版本哈希与条款见 data/public/hong_kong_wdi/metadata.json。

运行 `python -m macro_forecast.robustness`，固定比较(初始年数,滞后年数)=(15,2),(12,2),(18,2),(15,3)，仅在共同目标年份报告，保留逐年误差，不根据测试成绩选择赢家。年滞后及月度发布滞后均为假设，不是真实历史发布日历；最新修订数据不构成实时回测。合成数据生成形式接近线性模型，高拟合度不能外推。
