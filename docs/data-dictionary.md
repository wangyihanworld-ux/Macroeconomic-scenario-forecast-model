# 数据字典与建模口径

## 历史数据

| 字段 | 单位 | 含义 |
|---|---:|---|
| month | 月 | 月初日期，业务主键 |
| gdp_growth | % | 合成年化 GDP 增长率 |
| inflation | % | 合成年化通胀率 |
| unemployment | % | 合成失业率 |
| consumer_confidence | 指数 | 合成消费者信心指数 |
| fx_index | 指数 | 合成汇率指数 |
| revenue_mn | 百万元 | 合成企业月度收入 |

## 模型

收入由截距、五项宏观指标和月份的正弦/余弦季节项共同解释。参数使用普通最小二乘法估计。拟合值加残差必须与实际收入逐行勾稽。

## 回测

前 36 个月作为首次训练窗口，随后每月扩展训练样本，只预测下一个未参与估计的月份，共形成 24 个样本外预测。MAPE 为绝对百分比误差的算术平均。

## 情景

压力、基准和乐观情景各含 12 个月假设。情景之间同时改变 GDP、通胀、失业、消费者信心和汇率，因此结果用于整体条件比较，不用于识别单一变量的因果效应。
